# 本站 IP 参考评分 v2

规则版本：`ip-reference-score-v2`。这是待用户样本校准的产品规则，不是安全概率、账号安全保证或应用可用率。

参考 [MyIP 的公开评分解释](https://github.com/jason5ng32/MyIP/blob/main/frontend/utils/ip-score-details.js)分别呈现网络属性、匿名用途、滥用信誉与 ASN 环境。MyIP 的最终算分服务没有在该仓库公开；本站不声称复现其私有算法。

## 公式与高分门槛

```text
本站参考分 = floor(min(Net.Coffee 有效原分, 所有适用规则上限))
```

只接受有限的 0–100 原分。缺少有效原分时不补成 100 或 0；VPN、代理、Tor、滥用四项中至少两项有有效报告，或存在阳性风险/用途记录，才满足最低字段门槛。

当前综合 IP 信誉仍只有 Net.Coffee，**最高 79 分，不开放 80 分以上档位**。ASN-DROP 未列入、Tor 未检出、国家/归属一致、CIRCL 有排名，都不能解除这个限制。新增风险背景数据不等于新增一套独立综合 IP 信誉评分。

| 条件                                 |       最高分 | 解释                                   |
| ------------------------------------ | -----------: | -------------------------------------- |
| 单一综合 IP 信誉来源                 |           79 | “未检出”不足以支持高分                 |
| ASN 风险证据缺失、失效或归属无法确认 |           60 | 不确定性限制，不表示发现恶意           |
| 其他核验资料缺失、来源失败或过期     |           60 | 不把失败当未检出                       |
| 来源或类型分歧                       |           60 | 保留相反记录                           |
| ASN 命中 Spamhaus ASN-DROP           |           20 | 严重网络风险背景，与该 IP 自身滥用分开 |
| Tor / 代理 / VPN                     | 40 / 50 / 60 | 用途限制，不等同恶意行为               |
| 爬虫标记                             |           70 | 自动化用途背景                         |
| 该 IP 滥用记录                       |           20 | 保留原始记录，未知日期不臆造衰减       |
| 其他非信息级威胁                     |           40 | 待核实的来源报告                       |
| Bogon 异常                           |           10 | 地址/路由异常待核实                    |

多个条件取最严格上限，不累加扣分。已确认的 Tor、VPN、代理、爬虫用途标签不再当作同一条滥用重复计算。住宅、机房、移动、公共服务类型不直接加减分。

## ASN 证据

### Spamhaus ASN-DROP

- 官方来源：<https://www.spamhaus.org/drop/asndrop.json>。用途与条款：[官方说明](https://www.spamhaus.org/blocklists/do-not-route-or-peer/)、[使用条款](https://www.spamhaus.org/drop/terms/)。
- 仓库更新任务下载原始 JSON Lines，严格校验 ASN、记录数、发布时间及版权；构建复用已核验文件。保留官方版权、日期与条款，不将数据宣称为本站原创。
- GitHub Actions 每 6 小时检查更新资格，距离上次下载至少 24 小时才向官方请求一次。文件与回执保存在 `data/`，失败不提交。运行时优先读部署快照，必要时读取本仓库的公开镜像并缓存，访客请求不直连 Spamhaus。
- 快照有效期为 36 小时。部署文件超过 24 小时后检查本仓库的更新镜像（按小时缓存），无需等待新部署；两处都过期或失败则显示过期/未知并限制评分。不得用旧名单确认命中或未列入。
- ASN 来自 Net.Coffee 的 IP 归属；ASN 归属有分歧、ASN 不一致或来源失效时暂停匹配。未列入只表示有效快照中没有该条目，不代表网络信誉良好。

### CIRCL BGP Ranking

- [官方服务](https://www.circl.lu/services/bgp-ranking/)和[API 源码说明](https://github.com/D4-project/BGP-Ranking)。
- 通过公开 API 查询**上一个完整 UTC 日**，同时核验历史点是否匹配 ASN、日期及原始指标，避免把当天未完成排名当稳定结论。
- 显示排名日期、风险位置、参与排名的网络数及原始指标。位置越靠前表示风险排名越靠前；参与排名的网络不等于全部 ASN，也不是全网滥用占比或安全概率。
- 结果按 ASN/日期缓存，失败退避、超时或日期无法验证时显示不可用。CIRCL 当前只作背景，不给单个 IP 直接加减分，也不解除单源上限。

## 例子

| 合成输入                           |   本站分 |
| ---------------------------------- | -------: |
| 原分 95，字段完整、ASN-DROP 未列入 |       79 |
| 原分 95，ASN 风险证据不可用        |       60 |
| 原分 95，ASN-DROP 命中             |       20 |
| 原分 100，仅 VPN 标记              |       60 |
| 原分 100，Tor 与代理               |       40 |
| 原分 50，IP 滥用及 Tor             |       20 |
| 原分 5，ASN 或 IP 有风险记录       |        5 |
| 没有有效原分或最低字段门槛未满足   | 暂不评分 |

80–100 为未来的“参考较高”档，当前不开放；50–79“需留意”，0–49“重点核实”。分档并非经过验证的安全等级。来源原分、风险主结论、来源分歧及证据缺口全部保留。

## API 与用户验收

- API v1 `score/status` 保持兼容；v2 `reputation.value` 保留原分。
- v2 `assessment.scoring.value/limits/rule_version` 为本站参考分和规则，`calibration=heuristic_unvalidated`。
- `assessment.explanation.asn` 提供 ASN-DROP 判断及 CIRCL 背景。首页、详情页与 v2 使用同一规则。
- `/api/ip/evidence/<IP>?asn=<ASN>` 接受调用方提供的 ASN，仅查询该 ASN；接口本身不验证 IP→ASN 映射。页面和评分函数只接受与主来源一致且无归属分歧的记录。
- 测试反馈请记录 IP、本站分/原分、规则版本、ASN 名单状态、数据日期、实际用途和实际问题。验证码/拒绝也可能受账号、设备和访问频率影响，不能单凭一次结果倒推出 IP 恶意。
