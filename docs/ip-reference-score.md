# 本站 IP 参考评分 v1

规则版本：`ip-reference-score-v1`。这是可检查的产品规则，尚未经真实任务结果校准，不是安全概率、账号安全保证或应用可用率。

参考 [MyIP 的公开评分解释](https://github.com/jason5ng32/MyIP/blob/main/frontend/utils/ip-score-details.js)：网络属性、匿名用途、滥用信誉、ASN 环境分别展示，并采用 80/50 的显示分档。MyIP 的最终算分服务未在该仓库公开；本文的上限属于本站设计，不声称复现其私有算法。

## 公式

```text
本站参考分 = floor(min(Net.Coffee 有效原分, 所有适用规则上限))
```

只接受有限的 0–100 数值作为原分。缺少有效原分时不补成 100 或 0；无足够风险字段时也暂不评分。原始字段始终单独保留，不改写第三方原值。

| 条件                               | 最高分 | 含义                                        |
| ---------------------------------- | -----: | ------------------------------------------- |
| 综合信誉仅有 Net.Coffee 一个来源   |     85 | 单源试行上限，不能因 Tor 或归属库可用而解除 |
| 核验资料缺失、已请求来源失效或过期 |     60 | 不确定性限制，不表示已发现恶意              |
| 来源或类型有分歧                   |     60 | 保留相反记录，不以多数票抹除                |
| Tor 出口标记                       |     40 | 匿名用途限制，不等于用户恶意                |
| 代理标记                           |     50 | 用途限制，不等于用户恶意                    |
| VPN 标记                           |     60 | 用途限制，不等于用户恶意                    |
| 爬虫用途标记                       |     70 | 自动化用途提示，不等于用户恶意              |
| 滥用记录                           |     20 | 已报告记录需要重点核实，未知日期不臆造衰减  |
| 其他非信息级威胁记录               |     40 | 保留来源报告，不能直接推断已证实攻击        |
| Bogon 异常标记                     |     10 | 地址分类/路由异常需要核实                   |

多个条件只取最严格上限，不累加扣分。同一风险被多个服务或多个标签报告时，不会重复扣分。已经由对应阳性标记解释的 Tor、VPN、代理、爬虫用途标签，不会再次按滥用处理；无法与已有标记对应的威胁标签保留为待核实记录。

网络类型（住宅、机房、移动、公共服务）只作说明，不加减分。尚无 ASN 滥用占比数据，ASN 信誉保持“未评估”，不会把缺失维度当满分。不同用途的地址不应仅凭此分数作统一优劣排名。

## 证据门槛与显示

- VPN、代理、Tor、滥用四个字段中至少两个有可用报告，或存在已报告的阳性用途/风险记录，才满足风险字段的最低门槛。日期和来源有效性仍由核验规则检查。
- 过期、样例、未导入和失败的来源不产生阳性/阴性结果。可选 IPinfo Lite 未配置时明确显示未导入；归属核验成功也不能算第二家综合信誉来源。
- 同时保留“存在待核实风险”“来源存在分歧”“证据不足”“存在匿名用途标记”等主结论与发现。评分不清除这些提示。
- 80–100 显示“参考较高”，50–79 显示“需留意”，0–49 显示“重点核实”；这些是参考分档，不是经过验证的安全等级。
- 当前单源上限为 85，因此即使来源给 95/100 或 100/100，也不会显示本站满分。

## 例子

| 合成输入                         |                          本站分 |
| -------------------------------- | ------------------------------: |
| 原分 95，完整字段均未检出        |                              85 |
| 原分 100，VPN 标记               |                              60 |
| 原分 100，Tor 与代理标记同时存在 |                              40 |
| 原分 50，滥用和 Tor 标记同时存在 |                              20 |
| 原分 5，存在滥用记录             |                               5 |
| 原分 95，关键资料缺失            | 60 或暂不评分（最低门槛未满足） |
| 没有有效原分                     |                        暂不评分 |

## 接口与一致性

API v1 的 `score/status` 维持兼容。API v2 中：

- `reputation.value`：第三方原始分。
- `assessment.scoring.value`：本站规则参考分。
- `assessment.scoring.limits`：适用条件与上限。
- `assessment.scoring.calibration`：`heuristic_unvalidated`。
- `assessment.conclusion` / `assessment.explanation`：主结论与来源证据。

首页与详情页共享同一免费证据查询和评分函数；v2 API 也调用相同的 Tor/IPinfo Lite 核验与计算规则。同一规则版本、相同源数据与时效条件下，结果一致。数据刷新前显示核验中，避免把尚未完成的分数当成完整结果。

后续通过实际误判样本和明确用途验证再调整规则；变更上限或分档时升级规则版本。
